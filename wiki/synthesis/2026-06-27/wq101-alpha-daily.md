## WorldQuant 核心因子说明

| 因子编号 | 因子名称 | 公式逻辑 | 信号方向 |
|----------|----------|----------|----------|
| Alpha#1 | 价格动量 | Rank(Correlation(Delay(close,1), close, 10)) | 正值 = 趋势延续 |
| Alpha#6 | 量价相关性 | Correlation(open, volume, 10) | 正值 = 量价齐升 |
| Alpha#12 | 量价背离 | sign(delta(volume, 1)) * (-1 * delta(close, 1)) | 正值 = 缩量上涨/放量下跌 |
| Alpha#19 | 均值回复 | (-1 * rank((stddev(abs((close-open)),5) + (close-open) + rank(correlation(close,open,10))))) | 正值 = 超卖反弹 |
| Alpha#30 | 波动率动量 | (-1 * rank(((2*scale(rank(((((close-low)-(high-close))/(high-low))*volume))) - scale(rank(delta(close,3))))) * sum(volume,5)) | 正值 = 高波动+放量 |
| Alpha#41 | 趋势强度 | (((high * low)^0.5) - vwap) | 正值 = 价格高于 VWAP |
| Alpha#53 | 日内反转 | (-1 * Delta((((close - low) - (high - close)) / (close - low)), 9)) | 正值 = 短期超卖反转 |

## 核心选股策略

本期选股策略围绕 **"Great Rotation 2.0"** 主题：

1. **动量延续（Alpha#1/#6）**：存储/Semi Equipment/AI 基础设施强者恒强，MU/AMAT/MRVL/SNDK 量价共振
2. **均值回复（Alpha#19/#53）**：超卖的 Mega-Cap 科技（GOOGL/MSFT）和防御板块（JNJ/PG）反转信号积累
3. **趋势强度（Alpha#41）**：工业/能源/医疗趋势突破（CAT/XOM/LLY），价格稳定高于 VWAP
4. **量价背离（Alpha#12）**：金融（JPM/BAC）缩量企稳信号，确认卖压衰竭
