## 二、因子框架与打分方法

### 2.1 使用的核心因子（WorldQuant "101 Formulaic Alphas"）

| 因子 | 公式（简化） | 因子逻辑 | 本文用法 |
|------|--------------|----------|----------|
| **Alpha#1** | `rank(corr(delay(close,1), close, 10))` | 短期价格自相关 = 动量持续性 | 识别趋势延续型标的 |
| **Alpha#6** | `corr(open, volume, 10)` | 开盘价-成交量相关性 = 量价确认 | 上涨是否伴随放量（健康动量） |
| **Alpha#12** | `sign(delta(volume,1)) * (-delta(close,1))` | 放量下跌次日反转 / 缩量回调低吸 | 事件催化后放量突破的短线确认 |
| **Alpha#19** | `-(stddev(abs(close-open),5) + (close-open) + corr(close,open,10))` | 波动收敛 + 阴阳线结构 = 均值回复 | 超跌优质股的反转入场窗口 |
| **Alpha#30** | 复合：`-rank(...)*sum(volume,5)`（量加权量价背离） | 波动率/异常放量预警 | 财报前事件风险折价项 |
| **Alpha#41** | `sqrt(high*low) - vwap` | 价格重心高于 VWAP = 承接强度 | 中期趋势健康度 |
| **Alpha#53** | `-1 * delta((close-low-(high-close))/(close-low), 9)` | 日内收盘位置的变化率 = 反转 | 深度回调后的修复信号 |

### 2.2 打分规则（综合评分 1–10）

```
综合分 = 动量质量 (0–3)      # Alpha#1/#41：趋势方向、持续性、是否过热
       + 量价确认 (0–2.5)    # Alpha#6/#12：放量结构、资金介入证据
       + 基本面催化 (0–3)    # 订单/backlog/合同/回购等可验证事件
       + 反转修复加分 (0–1.5)# Alpha#53/#19：仅对超跌反转类标的计分
       − 事件风险折价 (0–2)  # Alpha#30：财报临近、极端涨幅(RSI)、拥挤度
```

筛选域：市值 > $10B 的美股大中盘；剔除无法从公开报道获得近期信号的标的。
