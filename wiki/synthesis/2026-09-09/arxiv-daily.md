### Don't Drop Dropout: Optimizing Layer Sparsity for Efficient LLM Training and Inference

| Field | Detail |
|-------|--------|
| **arXiv** | [2609.05275](https://arxiv.org/abs/2609.05275) |
| **Authors** | Mostafa Elhoushi, Alex Pretko, Nolan Dey, Bin Claire Zhang, Gavia Gray, Gurpreet Gosal, Abdulrahman Mahmoud, Shane Bergsma, Joel Hestness |
| **Institution** | Cerebras Systems |
| **Venue** | ICML 2026 |
| **Abstract** | Layer dropout (stochastic depth) has been shown to enable faster training, higher accuracy, and robustness to zero-shot layer pruning. This study shows layer dropout should be used in state-of-the-art LLM training, establishing best practices and scaling analysis. With optimal layer distribution, time schedule, and optimizer hyperparameters, layer dropout leads to lower loss at the same training FLOPs. LLMs can achieve lower validation loss while saving up to 25% of training FLOPs. Layer dropout enables early exit, intermediate-layer skipping, and self-speculative decoding, yielding up to 1.5× inference speedup. Evaluated across 2400+ experiments on models from 271M to 8.2B parameters and datasets up to 160B tokens on Cerebras CS-3. |
| **Key Innovations** | Systematic revival of layer dropout for modern LLMs; 25% FLOP savings; 1.5× inference speedup via self-speculative decoding; comprehensive scaling study |
| **Tags** | `LLM`, `efficiency`, `dropout`, `inference-speedup` |

### ACE: Adaptive Calibration-Free Expert Skipping for MoE-based LLMs

| Field | Detail |
|-------|--------|
| **arXiv** | [2609.05228](https://arxiv.org/abs/2609.05228) |
| **Authors** | Zukang Xu, Zhixiong Zhao, Xing Hu, Jiangyong Yu, Houji Wen, Jun Li, Zhe Jiang, Dawei Yang |
| **Institution** | Not specified |
| **Abstract** | MoE architectures activate fixed top-k experts per token, causing redundant computation. ACE is a training-free, calibration-free framework for token-adaptive expert skipping. It uses Global Spectral Proxy (GSP) to estimate transformation capacity from gate/up/down projections and Router-Conditioned Refinement (RCR) to build expert-specific direction prototypes. At 50% skipping ratio on Qwen3.6-35B-A3B, ACE reduces WikiText-2 perplexity by 7.96% and improves downstream accuracy by 4.15 pp. |
| **Key Innovations** | Training-free adaptive expert skipping; dual GSP+RCR estimation; offline expert statistics with online table lookups; 50% skip ratio with strong perplexity gains |

### UniCon: A Unified Context-Centric Modeling Paradigm for CTR Prediction

| Field | Detail |
|-------|--------|
| **arXiv** | [2609.03290](https://arxiv.org/abs/2609.03290) |
| **Authors** | Jiajun Cui, Zhengqi Xu, Fan Zhang, Zhangteng, Gu Tang, Honghong Zhu, Mengxi Wu, Yulin Liang, Xingxing Wang |
| **Institution** | Meituan |
| **Abstract** | Existing unified CTR models unify sequential and non-sequential signals at the token level, which is misaligned with the underlying decision process. User behavior is inherently a sequence of homogeneous context units. UniCon treats the request context as the basic modeling unit and organizes history and prediction targets as homogeneous context units. Intra-context attention captures local coupling (Locality), while inter-context attention models dynamic evolution across contexts (Dynamics). On Meituan search advertising: +0.0139 offline AUC, +3.09% RPM, +2.07% CTR, +2.95% revenue online. |
| **Key Innovations** | Context-centric unified modeling; homogeneous context units bridging history and target; intra/inter-context attention; production-validated on Meituan |
