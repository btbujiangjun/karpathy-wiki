## 七、AI 热点主题汇总（9/4-9/5）

### 7.1 OpenAI GPT-6 Astra 大众版开闸（9/3 发布 → 9/4 分阶段推送）
- **定价**：$10 / $50 per 1M tokens（输入/输出），缓存输入 $1、缓存写入 $12.50；**>272K token 长上下文整单翻倍**（输入 $20 / 输出 $75）；Batch / Flex 半价、Fast 模式 ~2x 价换 ~2.5x 速度
- **对比**：为 GPT-5.6 Sol 的 2.5 倍、与 Anthropic **Claude Fable 5.1 同价**；Brockman："按 token 定价没有意义，应按完成任务计费"
- **能力**：1.05M context / 128K output；Agents' Last Exam **59.3%**（领先 Claude Opus 5 的 55.5%、GPT-5.6 Sol 的 53.6%）；OSWorld 2.0 时长 **-47%**、输出 token **-65%**；已接入 API / Azure / AWS Bedrock
- **产业链含义**：推理成本中枢抬升 + Agentic 工作量上升 → 利好算力/推理基础设施；微软 Azure 同步供给

### 7.2 微软 Project Zenith —"本地推理"新叙事
- 开发者类 PC 开箱即编码：≥64GB 统一内存 + >250GB/s 带宽，本地跑 30B+ 模型（不计量）；首发 **AMD Ryzen AI Halo**
- 发布日 MSFT -2.04%：市场短期理解为"减少 metered cloud token 依赖"利空云推理；长期看是 Agentic 工作负载边缘化的铺垫
- **与 GPT-6 Astra（云端高价）形成镜像**：云端 vs 本地两种小模型/大模型协同范式同台

### 7.3 软件股回调 — 反弹中继还是见顶
- Barron's：《Palantir Heads for Worst Day in 7 Months. It Isn't the Only Software Stock Sinking.》——PLTR 单日 -3~4%，前两日 +6.4% 反弹部分回吐
- 基本面（Agentforce ARR $15 亿、Palantir 收入 +93%）未变，属**估值先行回调**；9/16 Dreamforce 为下一催化检查点

### 7.4 数字货币行情外溢
