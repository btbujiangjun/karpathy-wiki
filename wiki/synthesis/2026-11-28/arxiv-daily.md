### 1.1 Building a Unified Inline Code Editing Model for GitHub Copilot
- **Authors**: Microsoft CodeAI Team, Microsoft VS Code Team, Julia Gong, Benjamin Liggett, Shengjie Ma, Ulugbek Abdullaev, Zhehui Liao, Benjamin Steenhoek, Gaurav Mittal, Fuhui Fang, Satarupa Guha, Hang Zhao, Anand Mooga, Cheng Long, Benjamin Simmonds, Soojin Choi, Luciana Abud, Nathan Halstead, Alexandru Dima, Yu Hu, Elsie Nallipogu
- **Institution / Company**: Microsoft (Microsoft CodeAI Team & Microsoft VS Code Team; GitHub Copilot); author list includes Microsoft staff
- **Published**: 2026-11-24 · cs.SE, cs.CL, cs.LG · [arXiv:2611.33314](https://arxiv.org/abs/2611.33314) · 67 pages, 31 figures, 21 tables
- **Abstract**: AI-assisted coding ranges from fully agentic coding to inline code suggestions in the editor. Inline suggestions require predicting a developer's most likely next edit from an editing session. The next edit may lie at the cursor, in nearby lines, or farther away, and one editing intent can span several of these. The preceding system queries separate completion, nearby edit, and long-distance edit models, each with its own output format, in a fixed sequence; it thus cannot express intents spanning distant locations in one response, can require several sequential model calls per suggestion, and prioritizes completion even when a correction would serve better. We present a unified model that predicts all three edit types in one output space: a sequence of anchored diff patches specifying locations, deleted lines, and added lines. This representation permits multiple edits per response, so the client can serve later edits from a cache without further model calls. We train this model in two phases, first unifying next edit and long-distance edit prediction, then adding code completion. We synthesize multi-edit supervision from single-edit data via model pseudolabeling and edit history playback. We use a binary LLM-graded reward, a patch validity taxonomy shared by data filtering, reward, and evaluation, and grader boosting for targeted failure modes. Phase 2 also adapts how the client processes and presents model outputs. In controlled online A/B experiments in GitHub Copilot, Phase 1 significantly reduces time to display by 6.77% and output tokens by 58.93% relative to the three-model baseline. In Phase 2, the 3-in-1 model and client adaptations reduce dismissed suggestions per user by 10.06% relative to the 2-in-1 model paired with the completion model. Throughout this report, we also share our methodology and learnings in evaluation, training, and end-to-end model and system design.
- **Key innovations**:
  - One unified model for three inline edit types — completion, nearby edit, long-distance edit — in a single output space of anchored diff patches (locations + deleted/added lines); multiple edits per response, cacheable for follow-ups.
  - Two-phase training: Phase 1 unifies next-edit + long-distance edit; Phase 2 adds completion; multi-edit supervision synthesized via model pseudolabeling + edit-history playback; binary LLM-graded reward + shared patch-validity taxonomy + grader boosting.
  - Online A/B in GitHub Copilot: Phase 1 −6.77% time-to-display & −58.93% output tokens vs 3-model baseline; Phase 2 −10.06% dismissed suggestions/user vs 2-in-1 + completion model.

- **Abstract**: We present AliceAI-Foundation-80B-A3B-Base, a mixture-of-experts language model with 80 billion total parameters and approximately 3 billion active parameters per token, trained from scratch at Yandex and released under the Apache 2.0 license. - **Key innovations**:

### 1.3 SAG-Mem-1.0 Technical Report
- **Authors**: Yuchao Wu, XingCheng Liang, Xuanze Wang, Yini Huang, Yue Wu
- **Institution / Company**: Zleap AI (emails @zleap.com); correspondence jomy@zleap.com
- **Published**: 2026-11-24 · cs.CL, cs.IR · [arXiv:2611.33124](https://arxiv.org/abs/2611.33124)
- **Abstract**: Long-term conversational memory requires retrieving complementary facts scattered across dialogue sessions, including intermediate evidence with limited similarity to the original question. Existing approaches often rely on derived memory representations or persistent relational structures, introducing construction costs and potentially losing source details. We present SAG-Mem, a conversational memory framework that preserves complete dialogue messages in non-overlapping chunks and discovers complementary evidence through query-time lexical expansion. Memory construction requires no model inference, using a lexical index without LLM-based extraction, summarization, or semantic relation construction. At query time, BM25 retrieves initial candidates, an evidence evaluator identifies useful chunks, and lexical cues from selected evidence guide an additional retrieval round. Retrieved dialogue is further annotated with calendar interpretations of supported relative-time expressions, preserving the original wording and temporal granularity. We also introduce SAG-Mem-Lite, an alternative configuration that replaces evidence scoring with embedding-based candidate scoring, achieving lower operational cost than Full Context and all memory-based baselines across both benchmarks with low query latency. On LoCoMo and LongMemEval, SAG-Mem achieves overall scores of 83.08 and 80.20, respectively, the highest among the evaluated methods on both benchmarks. On LongMemEval, it exceeds the strongest compared baseline by 7.20 points. SAG-Mem-Lite achieves scores of 77.09 and 77.20, respectively. These results support dialogue preservation and evidence-guided retrieval expansion as an effective design for long-term conversational memory.
- **Key innovations**:
  - SAG-Mem conversational memory: keep complete dialogue messages in non-overlapping chunks; no LLM extraction/summarization; no persistent relational structure.
  - Query-time lexical expansion: BM25 → evidence evaluator → second retrieval round using lexical cues from selected evidence; temporal annotation of relative-time expressions while preserving original wording.
  - SAG-Mem-1.0 (LoCoMo 83.08, LongMemEval 80.20, highest among evaluated); SAG-Mem-Lite (77.09/77.20, lower cost than full context + memory baselines).

### 1.4 Agent-as-a-Verifier: From Scores to Evidence for General Verification
- **Authors**: Yuxuan Sun, Hao (Mark) Chen, Nagarajan Natarajan, Sushrut Karmalkar, Niranjani Prasad, Amit Sharma, Hongxiang Fan
- **Institution / Company**: Imperial College London + Microsoft Research; accepted NeurIPS 2026 Workshop "Who Verifies the Agents?"
- **Published**: 2026-11-25 · cs.LG · [arXiv:2611.34132](https://arxiv.org/abs/2611.34132) · 15 pages, 3 figures, 3 tables. Accepted at the NeurIPS 2026 Workshop: Who Verifies the Agents? Toward Reliable Agent Development
- **Abstract**: Verification is increasingly critical across various inference and learning paradigms, such as test-time scaling, recursive intelligence and automated research, where feedback can improve efficiency and optimization. Common score-based verifiers, or discriminative reward models, predict a scalar reward for an output. While useful for filtering, rewarding, and ranking, such scores provide no explicit, auditable evidentiary basis for the judgment. In parallel, although existing generative process reward models offer text feedback, most designs do not fully exploit agentic capabilities, such as tool use and iterative reasoning, which are essential for fact-checking and fine-grained claim verification. In this paper, we address these limitations by introducing Agent-as-a-Verifier, an agentic, certificate-producing verification system that places role-separated LLM agents inside a formal-methods-inspired claim-obligation-certificate protocol. Given a generation candidate, Agent-as-a-Verifier produces a certificate by extracting a verdict-blind dependency graph of claims, independently compiling the task's acceptance contract, and deriving checkable obligations. On Terminal-Bench 2.1, Agent-as-a-Verifier achieves higher accuracy than the state-of-the-art approach. Across different downstream applications, the augmented agent also outperforms the plain agent on FrontierMath and CyberGym. More importantly, Agent-as-a-Verifier is able to identify reward-hacking solutions that deceive the benchmark evaluator, highlighting its broader potential for iterative and recursive agent optimization. Code is available at https://github.com/sunyxedu/General-Verifier
- **Key innovations**:
  - Agent-as-a-Verifier: agentic, certificate-producing verification; role-separated LLM agents inside a formal-methods-inspired claim–obligation–certificate protocol (replaces scalar score-only verifiers / discriminative reward models).
  - Pipeline: verdict-blind dependency graph of claims → independently compiled acceptance contract → checkable obligations → certificate; uses tool use + iterative reasoning for fact-checking/fine-grained claim verification.
  - Higher accuracy than SOTA on Terminal-Bench 2.1; augmented agent outperforms plain agent on FrontierMath + CyberGym; detects reward-hacking solutions that deceive benchmark evaluators.

### 1.5 Knowledge-Base Gradient Descent: Self-Structuring Learning through Question Answering
- **Authors**: Masahiro Kato
- **Institution / Company**: The University of Tokyo
- **Published**: 2026-11-25 · cs.AI, cs.LG · [arXiv:2611.34841](https://arxiv.org/abs/2611.34841)
- **Previously reported in wiki**: wiki/synthesis/2026-11-27/arxiv-ai-search.md (not new to wiki; re-listed for this daily scan)
- **Abstract**: We consider the problem of constructing knowledge bases for applications based on large language models, in which the structure of a knowledge base determines how an application can retrieve and connect the information needed to answer a question. We study Self-Structuring Learning, a setting in which questions and expected answers guide the construction of a persistent knowledge base whose editable structure can be a graph schema or the organization of linked knowledge documents. We propose Knowledge-Base Gradient Descent, which diagnoses discrepancies between expected answers and responses obtained through the current knowledge base. At each round, the method proposes a structural edit, rebuilds the knowledge base, and adopts the edit when the learning loss decreases. The retained structure is evaluated on other questions about the same sources. By randomizing over candidate edits, we express the loss change of an edit as a derivative with respect to the probability of selecting it, and we evaluate joint edits as single candidates because their changes interact. Schema Descent instantiates the method for graph schemas. In experiments on large documents, each a bundle of research papers, the updated knowledge cards and graph schemas obtain higher mean Answer F1 on held-out generated questions than their initial structures, with schema gains in every document. On human questions, mean F1 rises for schemas and falls for cards: the updated structures serve the kind of question they were learned from.
- **Key innovations**:
  - Knowledge-Base Gradient Descent / Self-Structuring Learning: questions + expected answers drive construction of a persistent, editable knowledge base (graph schema or linked knowledge documents).
  - Each round diagnoses expected-vs-actual answer discrepancies, proposes a structural edit, rebuilds the KB, keeps the edit iff loss decreases; "Schema Descent" instantiates it for graph schemas.
  - Loss change expressed as a derivative w.r.t. edit-selection probability (randomized candidate edits); joint edits scored as single candidates; retained structure validated on held-out questions about the same sources.

### 2.1 Grounding User Preferences in Shared Multimodal Concepts for Recommendation
- **Authors**: Ao Xu, Jinhui Huang, Wenqiang Tang, Tiehua Mei, Hongru Hou, Hengrui Chen, Jiaqing Liang, Deqing Yang
- **Institution / Company**: Fudan University (School of Data Science); accepted WSDM 2027 main conference; code at github.com/Garden1a-X/MKGE
- **Published**: 2026-11-25 · cs.IR · [arXiv:2611.34436](https://arxiv.org/abs/2611.34436) · Accepted at WSDM 2027 (Main Conference). 10 pages, 7 figures, 6 tables
- **Previously reported in wiki**: wiki/synthesis/2026-11-27/arxiv-ai-search.md (not new to wiki; re-listed for this daily scan)
- **Abstract**: Multimodal recommendation has substantially advanced item understanding by incorporating rich visual and textual content. Yet user preferences are still commonly encoded as implicit signals tied to individual items, leaving recurring semantic factors without persistent identities that can be shared across items. We introduce MKGE, a multimodal knowledge graph framework that represents these factors as canonical, addressable concepts. MKGE induces a domain-adaptive concept vocabulary from item images and titles, grounds each user's interaction history in supported concepts, and jointly models direct user-item evidence and concept-mediated preference signals. By turning recurring semantics into shared coordinates, MKGE enables evidence from different items to accumulate around the same preference factors. Extensive experiments on three public benchmarks demonstrate that MKGE consistently outperforms collaborative, knowledge-graph, multimodal, and recent LLM/MLLM-based recommenders across all six reported metrics. Controlled studies further demonstrate the importance of canonical concept identities and personalized user-concept correspondence, with especially pronounced gains over removing or rewiring the user graph for low-activity users. These results establish canonical multimodal concepts as effective units for preference modeling and transfer. Code, constructed knowledge graphs, and prompts are available at https://github.com/Garden1a-X/MKGE.
- **Key innovations**:
  - MKGE multimodal knowledge-graph framework: canonical, addressable concepts as shared coordinates instead of item-level implicit signals.
  - Domain-adaptive concept vocabulary induced from item images + titles; user history grounded in supported concepts; joint modeling of direct user-item + concept-mediated preference signals; evidence accumulates across items.
  - Consistently beats collaborative, KG, multimodal and LLM/MLLM recsys on 3 public benchmarks across 6 metrics; gains on low-activity users; canonical identities + personalized user-concept correspondence matter.

### 2.2 LazUnirec: Unifying Retrieval and Ranking in Multi-scenario Industrial Recommendation
- **Authors**: Xiaodong Li, Junfeng Zhang, Shichao Nie, Ziyue Guo, Yiming Liu, Xinxin Xu, Xurong Li, Jinyuan Dang, Zhanming Ou, Jianan Yan, Tao Luo, Xiaoyi Zeng
- **Institution / Company**: Alibaba International Digital Commerce Group (Beijing); deployed in online multi-scenario industrial recommendation
- **Published**: 2026-11-24 · cs.IR · [arXiv:2611.32590](https://arxiv.org/abs/2611.32590)
- **Previously reported in wiki**: wiki/synthesis/2026-11-27/arxiv-ai-search.md (not new to wiki; re-listed for this daily scan)
- **Abstract**: Modern industrial recommendation systems typically divide retrieval and ranking into two separate cascaded stages, leading to inconsistent optimization objectives, redundant encoding of user sequences, and a waste of computational resources. Previous efforts have investigated using Transformers to model both retrieval and ranking simultaneously. However, these studies still face two major limitations: (1) Since retrieval and ranking share a single Transformer backbone, the gradient conflict arises when the gradient directions of the two tasks are inconsistent. (2) When gradient conflict occurs, the model cannot determine a reliable direction for gradient updates. To this end, we propose a Unified Retrieval and Ranking approach for Multi-scenario Industrial Recommendation, termed as LazUnirec. Specifically, we construct task-shared and task-private parameters on the Transformer backbone to mitigate the gradient conflict. Wherein, for the attention components, we propose LoRA-modulated attention, enabling retrieval and ranking to share attention parameters while preserving task-private parameters. For the feed-forward networks (FFN), we present task-adaptive sparse mixture-of-experts (MoE) to mitigate gradient conflict by constructing task-shared and task-private experts. Moreover, we propose an uncertainty estimation that evaluates the gradient reliability of the retrieval and ranking, thereby guiding the model toward a more reliable gradient update direction when gradient conflict occurs. In addition, knowledge distillation from ranking to retrieval further enables cross-task knowledge transfer. Extensive offline experiments and online A/B testing demonstrate the effectiveness and superiority of LazUnirec. LazUnirec has been deployed in online multi-scenario industrial recommendation system and currently delivers significant gains for the platform.
- **Key innovations**:
  - LazUnirec: unify retrieval + ranking in one Transformer for multi-scenario industrial recommendation (no separate cascade).
  - Mitigates retrieval/ranking gradient conflict via task-shared + task-private params: LoRA-modulated attention; task-adaptive sparse MoE FFN (shared + private experts).
  - Uncertainty estimation of per-task gradient reliability guides updates; knowledge distillation ranking→retrieval; significant offline + online A/B gains.

### 2.3 User-Adaptive Fusion of Multiple Foundation Models for Recommender Systems
- **Authors**: Sunwoo Kim, Hyunjin Hwang, Geon Lee, Kyungho Kim, Kijung Shin
- **Institution / Company**: KAIST (Seoul); accepted WSDM 2027 main track; code github.com/kswoo97/UFFO
- **Published**: 2026-11-24 · cs.IR · [arXiv:2611.31951](https://arxiv.org/abs/2611.31951) · Published in the WSDM 2027 (Main Track)
- **Abstract**: Can recommender systems benefit from combining a collection of foundation models within and across modalities? While different foundation models may capture complementary aspects of item metadata, we find that naively combining their representations yields only marginal gains over using a single foundation model. We make a key observation: the users who benefit vary across foundation models. Motivated by this observation, we introduce UF2O, a user-adaptive approach for fusing multiple foundation models for recommendation. In a nutshell, UF2O models the contribution of each foundation model as user-specific by maintaining separate recommendation views and adaptively combining their scores for each user. By performing fusion at the score level, UF2O can also fuse heterogeneous foundation models without directly aligning their representation spaces. Extensive experiments that jointly combine four foundation models on four datasets show that UF2O outperforms existing fusion approaches in both static and sequential recommendation settings, with improvements of up to 7% over the strongest fusion baseline. The code, datasets, and supplementary materials for our work are available at https://github.com/kswoo97/UFFO.
- **Key innovations**:
  - UF2O user-adaptive fusion of multiple foundation models for recommendation: per-user weighting across models instead of naive representation merging.
  - Separate recommendation views per foundation model; score-level fusion → fuse heterogeneous models without aligning representation spaces; works for static + sequential recommendation.
  - Combines 4 foundation models across 4 datasets; up to +7% over strongest fusion baseline.

### 2.5 Multi-Modal Causal Disentanglement for Multi-Domain Sequential Audio Recommendation
- **Authors**: Yu Ren, Pengcheng Li, Weijun Xu, Hengzhong Zhou, Shufeng Ye, Qiang Xiao, Dongjing Wang, Chuanjiang Luo, Yong Li
- **Institution / Company**: Hangzhou Dianzi University + NetEase Cloud Music (Hangzhou); online A/B on NetEase Cloud Music
- **Published**: 2026-11-25 · cs.IR, cs.SD · [arXiv:2611.33628](https://arxiv.org/abs/2611.33628)
- **Abstract**: Modern music platforms expose users to heterogeneous audio content domains such as songs, playlists, and podcasts. Multi-domain sequential recommendation (MDSR) seeks to exploit such cross-domain behavior, yet two obstacles persist in practice. First, joint optimization across heterogeneous domains is prone to negative transfer, with high-traffic domains dominating the shared parameter space and suppressing weaker domains. Second, conventional ID-based collaborative signals fail to bridge domains that are semantically related but exhibit little behavioral overlap. This paper presents CAMAR, a multi-modal causal disentanglement framework for multi-domain audio recommendation. From a causal perspective, user behavior is modeled as the joint outcome of a domain-invariant preference and domain-specific preferences. Guided by this view, CAMAR factorizes user representations into domain-invariant and domain-specific components and enforces domain adversarial invariance together with orthogonality, restricting cross-domain interaction to the invariant subspace and suppressing harmful transfer paths. To strengthen cross-domain semantic coupling, CAMAR derives trainable semantic-ID embeddings from pre-trained text, vision, and audio features through residual quantization, yielding an end-to-end multi-modal adaptation tailored to recommendation. A transfer network imputes user representations for inactive domains, mitigating cross-domain cold start. Experiments on both public and industrial datasets demonstrate consistent gains over strong baselines. In online A/B tests on NetEase Cloud Music, one of China's largest music streaming platforms, CAMAR delivers consistent gains across all three domains in their main traffic scenarios, validating its effectiveness in multi-domain audio recommendation at scale.
- **Key innovations**:
  - CAMAR multi-modal causal disentanglement for multi-domain sequential audio recommendation (songs/playlists/podcasts).
  - Factorize user representation into domain-invariant + domain-specific parts; domain-adversarial invariance + orthogonality; restrict cross-domain interaction to invariant subspace; suppress negative transfer.
  - Trainable semantic-ID embeddings via residual quantization over text+vision+audio; transfer network for cold-start inactive domains; consistent gains offline + online A/B across all 3 domains.

### 3.1 Stable Gated DeltaNet-2: Understanding and Mitigating Recurrent State Instability
- **Authors**: Xichong Zhang, Xixuan Hao, Zhichen Liu, Le Zhou, Zeyu Zhang, Boyu Chen, Mingfei Lu, Zehao Lin, Bo Tang, Yonggang Zhang, Linyun Liu, Feiyu Xiong, Jianlin Su, Zhiyu Li
- **Institution / Company**: MemTensor + USTC + HKUST(GZ) + SUSTech + SJTU + HKUST + kexue.fm
- **Published**: 2026-11-25 · cs.CL, cs.LG · [arXiv:2611.34051](https://arxiv.org/abs/2611.34051)
- **Previously reported in wiki**: wiki/synthesis/2026-11-27/arxiv-ai-search.md (not new to wiki; re-listed for this daily scan)
- **Abstract**: Linear attention offers an efficient solution for long-sequence modeling via linear complexity and fixed-size recurrent states. Gated DeltaNet-2 (GDN-2) introduces independent channel-wise control over erasure and writing, enhancing state-update expressiveness and in-context retrieval, yet it suffers from training failures during long-context training. We trace these failures to the asymmetry between reading and modification directions during erasure, which yields non-normal erase operators whose directional gains accumulate across tokens, triggering exponential state growth even without new writes. To resolve this, we propose \model{}, employing symmetric erasure to ensure non-expansive state propagation and decay-regulated residual writing to preserve writing flexibility. Theoretically, we establish an $O(\sqrt{T})$ upper bound on recurrent state growth while retaining chunkwise parallel computation. Experiments on ~1.6B parameter models show that \model{} achieves stable training alongside improved long-context retrieval. Compared to GDN-2, it boosts the 128K average RULER score by 6.80 points in the recurrent setting and average accuracy across nine downstream tasks by 0.62 points in the hybrid setting.
- **Key innovations**:
  - Stable Gated DeltaNet-2 (Stable GDN-2): linear-attention recurrent model fixing training failures in Gated DeltaNet-2 long-context training.
  - Root cause: asymmetry between reading and modification directions during erasure → non-normal erase operators → exponential state growth; fix = symmetric erasure (non-expansive propagation) + decay-regulated residual writing.
  - O(√T) bound on recurrent state growth; chunkwise parallel retained; ~1.6B models: +6.80 128K RULER (recurrent), +0.62 accuracy (hybrid, 9 tasks).

### 3.2 State Space Attention: Learning Context-Dependent Memory Retention
- **Authors**: Ege Çakar, Cengiz Pehlevan
- **Institution / Company**: Harvard University (Department of Statistics; John A. Paulson School of Engineering and Applied Sciences); code github.com/Ege-Cakar/State-Space-Attention
- **Published**: 2026-11-25 · cs.LG, cs.CL · [arXiv:2611.33625](https://arxiv.org/abs/2611.33625) · 36 pages, 3 figures, 37 tables. Code: https://github.com/Ege-Cakar/State-Space-Attention
- **Abstract**: Standard attention's key-value cache grows linearly with context length. Bounding it raises the question of what a sequence model should retain for long-context reasoning. We argue this choice should be learned, and introduce State Space Attention (SSA), which learns to keep a bounded set of past representations and reads them with standard attention. A learned scorer rescores every chunk against newly arriving context and the rest of memory. A fixed-context Transformer is then the special case that always keeps the most recent tokens. We train the scorer and reader jointly, either moving gradually from a differentiable soft weighting of memories to hard retention, or with hard retention from the start. To produce signal for the scorer, we generate supervised samples during training, a technique we call recovery. We compare SSA with recurrent models, bounded-memory attention methods, and full-attention Transformers across retrieval, variable tracking, multi-hop reasoning, and language modeling. On our retrieval and reasoning benchmarks, SSA matches or comes within a few points of full attention on most tasks, far outperforms a Transformer with the same readable budget on every long-context retrieval task we evaluate, and matches or outperforms one with about 4 times that budget, while using constant inference memory. The largest remaining gap to full attention at small language model scale is on RULER. SSA makes a fixed number of tokens useful over a longer context, and since it reads memory with standard attention, we propose that it can be stacked with KV cache eviction methods. We also pretrain and post-train 400M-parameter models and measure how SSA's training and inference costs scale with context length and model size. Together, these experiments examine the capabilities and limitations of learned memory retention for long-context sequence modeling.
- **Key innovations**:
  - State Space Attention (SSA): bounded-memory sequence model; learned scorer rescores every chunk against new context + rest of memory to retain a bounded set of past representations; standard attention reads memory; fixed-context Transformer = special case.
  - Joint training of scorer + reader; soft→hard retention schedule or hard from start; "recovery" generates supervised signal for scorer; constant inference memory; stackable with KV-cache eviction.
  - Matches/nearly matches full attention on retrieval + reasoning; beats same-budget Transformer; ~4× readable-budget parity; 400M pretrained/post-trained; gap to full attention mainly RULER.

### 3.4 Learning from Recurrence: Internalizing Depth-Induced Preferences in Looped Language Models
- **Authors**: Hui Chen, Joshua Elsdon, Can Goksen
- **Institution / Company**: University of Wisconsin-Madison + Microsoft
- **Published**: 2026-11-24 · cs.CL, cs.LG · [arXiv:2611.33468](https://arxiv.org/abs/2611.33468) · 22 pages, 6 figures

### 3.5 Speculative Decoding for Semantic-ID-Based Generative Recommendations
- **Authors**: Harshal A. Chaudhari
- **Institution / Company**: Etsy Inc. (Brooklyn, NY); hchaudhari@etsy.com
- **Published**: 2026-11-24 · cs.IR · [arXiv:2611.32855](https://arxiv.org/abs/2611.32855) · 33 pages, 19 figures (23 pages main text, appendices A-E follow). Preprint
- **Previously reported in wiki**: wiki/synthesis/2026-11-27/arxiv-ai-search.md (not new to wiki; re-listed for this daily scan)
- **Abstract**: Generative recommender systems with Semantic IDs (SIDs) represent each item as a short sequence of $L$ discrete tokens and use a sequence model to predict the next item's tokens from a user's history. Even when the budget is too small to recover the exact top-$K$, SIDECAR, unlike beam search, reports the announced factor, allowing the serving system to stop early once a quality target or latency limit is reached.
- **Key innovations**:
  - SIDECAR for Semantic-ID (SID) generative recommenders: certify exact top-K retrieval under constrained beam search.
  - Approximate draft candidates + single tree-attention scoring pass bounding every unexplored SID prefix; certifies exact top-K if draft contains them; branch-and-bound trie expansion fallback ≤ L calls.

We evaluate CECP on both a neuroscience-inspired cooperative foraging task, and the popular ZSC benchmark Overcooked, under held-out partner and held-out environment conditions. CECP achieves the strongest performance among the compared baselines and attains state-of-the-art results under our evaluation protocol for human-AI collaboration. We analyze the model's latent representation encoded by the next-state prediction module, showing it can not only improve the performance of the cooperative AI, but also provide more interpretable latents, demonstrated by the inference of partner skill levels.
- **Key innovations**:
  - CECP (Cross Environment Co-Play): zero-shot coordination — jointly model partner diversity + environment diversity.
  - Two-stage: population of self-play agents across procedurally generated envs → cooperator policy trained vs partner population; next-state prediction module couples social + environmental reasoning.
  - SOTA under held-out partner + held-out environment (cooperative foraging + Overcooked); latents encode partner skill; interpretable.

### 6.4 Exploring Multi-Player Social Games as Verifiable Training Grounds for Large Language Models
- **Authors**: Keyu He, Michael Li, Jiarui Liu, Mingqian Zheng, Koichi Onoue, Tongshuang Wu, Maarten Sap
- **Institution / Company**: Carnegie Mellon University + Fujitsu Research of America; Qwen3 models; (no repo URL in abstract)
- **Published**: 2026-11-24 · cs.CL, cs.AI, cs.LG, cs.MA · [arXiv:2611.31821](https://arxiv.org/abs/2611.31821)
- **Previously reported in wiki**: wiki/synthesis/2026-11-25/arxiv-ai-search.md + wiki/synthesis/2026-11-25/game-rl-daily.md + wiki/synthesis/2026-11-26/game-rl-daily.md + wiki/synthesis/2026-11-27/game-rl-daily.md (not new to wiki; re-listed for this daily scan)
- **Abstract**: The training of socially intelligent language models often relies on large language model (LLM) judges, which are expensive, noisy, and vulnerable to reward hacking. Multi-player social games offer a natural alternative: they require open-ended communication to coordinate with teammates and infer hidden roles, while their rules provide an objective outcome which can serve as a verifiable reward for training. Using three social games, we explore how much social intelligence Qwen3 models can acquire through supervised fine-tuning (SFT) and reinforcement learning with verifiable rewards (RLVR). Results show that against a much stronger Gemma-3-27B model, SFT and RLVR raise the win rate of Qwen3-4B from 33% to 81% on the three trained games, and from 39% to 54% on three additional held-out games. In contrast, in-context strategies such as prompting improve the win rate of Qwen3-4B by only about 6 pp across the same games we train and evaluate on. Furthermore, we show that the gains from SFT and RLVR hold across the model sizes 1.7B, 4B, and 32B. Qualitative analyses of agent behavior show signs of stronger social intelligence; for example, trained agents tend to share information more openly, check each other's claims against public evidence, and coordinate their votes. More broadly, our results demonstrate that training LLMs on verifiable outcomes in social games can cultivate generalizable social behaviors, which offers a scalable path for building socially intelligent agents.
- **Key innovations**:
  - Multi-player social games as verifiable reward training grounds (no LLM judge); 3 social games; SFT + RLVR on objective outcomes.
  - Qwen3-4B win rate 33%→81% on trained games; 39%→54% on 3 held-out games; beats prompting; holds across 1.7B/4B/32B.
  - Emergent social intelligence: shares info, checks claims vs public evidence, coordinates votes; generalizable social behaviors; scalable socially-intelligent agents.

### 6.5 Computing Normal-Form Correlated Equilibria in Extensive-Form Games is in PPAD
- **Authors**: Vincent Cheval, Florian Horn, Soumyajit Paul, Mahsa Shirmohammadi
- **Institution / Company**: University of Oxford + CNRS IRIF (France)
- **Published**: 2026-11-25 · cs.GT, cs.CC · [arXiv:2611.34897](https://arxiv.org/abs/2611.34897)
- **Abstract**: We study the computational complexity of finding any normal-form correlated equilibria (NFCE for short) in the succinct games of extensive-form with perfect recall, which is considered as a major open problem in algorithmic game theory. Our main results place this problem in PPAD for an arbitrary numbers of players. Our second result establishes PPAD-hardness of computing such an NFCE with support size of at most quadratic in the size of the game, even for two-player games. The posed restriction on the support size in PPAD-hardness construction is motivated by our PPAD algorithm, which constructs an NFCE with support size quadratic in the size of the input extensive-form game.
- **Key innovations**:
  - Normal-Form Correlated Equilibria (NFCE) in succinct extensive-form games with perfect recall — a major open problem in algorithmic game theory — placed in PPAD for arbitrary number of players.
  - PPAD-hardness of computing NFCE with support size ≤ quadratic in game size, even for two-player games; matches the constructed PPAD algorithm producing NFCE with quadratic support.
