## 二、因子框架与打分方法

### 2.1 使用的核心因子（WorldQuant "101 Formulaic Alphas"）

| 因子 | 公式（简化） | 因子逻辑 | 本期用法调整 |
|------|--------------|----------|----------|
| **Alpha#1** | `rank(corr(delay(close,1), close, 10))` | 短期价格自相关 = 动量持续性 | 权重下调：主线标的动量普遍断裂 |
| **Alpha#6** | `corr(open, volume, 10)` | 开盘价-成交量相关性 = 量价确认 | 维持：区分健康回调与恐慌出货 |
| **Alpha#12** | `sign(delta(volume,1)) * (-delta(close,1))` | 放量下跌次日反转 / 缩量回调低吸 | 上调：本周放量下跌后的短线修复信号增多 |
| **Alpha#19** | `-(stddev(abs(close-open),5) + (close-open) + corr(close,open,10))` | 波动收敛 + 阴阳线结构 = 均值回复 | 上调：反转候选池扩容 |
| **Alpha#30** | 复合量加权量价背离 | 波动率/异常放量预警 | 权重上调至最高：财报周 + 议息周双重事件 |
| **Alpha#41** | `sqrt(high*low) - vwap` | 价格重心高于 VWAP = 承接强度 | 维持：验证防御型上涨的质量 |
| **Alpha#53** | `-1 * delta((close-low-(high-close))/(close-low), 9)` | 日内收盘位置变化率 = 反转 | 上调：本期核心超额收益来源 |

### 2.2 打分规则（综合评分 1–10）

```
综合分 = 动量质量 (0–2.5)     # Alpha#1/#41：本期权重下调
       + 量价确认 (0–2.5)    # Alpha#6/#12：回调中的承接证据
       + 基本面催化 (0–3)    # 订单/backlog/合同/回购等可验证事件
       + 反转修复加分 (0–2)  # Alpha#53/#19：本期权重上调
       − 事件风险折价 (0–2.5)# Alpha#30：财报/PCE/Warsh/ADR 供给四重事件
```

筛选域：市值 > $10B 的美股大中盘；剔除无法从公开报道获得近期信号的标的。
